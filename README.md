# JavaFX Pacman Game

A classic Pacman game implemented in Java using JavaFX.

## Features

- Classic Pacman gameplay
- Customizable maze generation
- Multiple ghosts with different behaviors
- Smooth animations and responsive controls
- Developed in Java and JavaFX

## Requirements

- Java 21 or higher
- JavaFX 23 or higher
- Gradle 8.14.2 or higher

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/dawciobiel/javafx-pacman-game.git
   cd javafx-pacman-game
   ```

2. Build and run with your preferred tool:

   Using Gradle:

   ```bash
   ./gradlew run
   ```
